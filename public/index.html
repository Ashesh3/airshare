A direct AirShare

AirShare is a small file handoff tool for sending files from one browser or terminal to another without storing file contents on disk.

  • Streams files directly through the server to waiting receivers
  • Works from browsers and command line tools
  • Allows multiple receivers to wait for the same shared file
  • Keeps the sender in control by requiring the sender tab or upload command to stay active

AirShare features

  • No configured file size limit
  • Direct send and receive links
  • File contents are not written to server storage
  • Terminal friendly
  • Mobile friendly

Use AirShare to send and receive files from your terminal

Sending files
curl -T <myfile> -s -L -D - http://localhost:3070/xfr | findstr /i airshare
wget --post-file <myfile> -S -o - http://localhost:3070/xfr
Receiving files
curl -s -J -O -L -D - http://localhost:3070/xfr
wget --content-disposition -S -o - http://localhost:3070/xfr
