A new AirShare

AirShare brings browser and terminal file transfers to a self-hosted, open-source app. It keeps the familiar live-streaming workflow, gives you control of the relay, and supports large files and multiple receivers without saving file contents on the server. Features include:

  • Fast streaming with backpressure and bounded memory
  • Separate sender and receiver links
  • Receiving a file from your terminal
  • Sending to multiple receivers at once
  • QR codes for sharing with another device
  • Channel links that survive server restarts

Keep the sender tab or terminal running during the transfer. File contents are never stored on the server, and no application file-size limit is configured by default.

AirShare is independent open-source software. Visit the project for source code, feedback, and self-hosting instructions.

Use AirShare to send and receive files from your terminal

Sending files

Sending a file with cURL 
curl -T "./myfile.zip" -L --max-redirs -1 -D - "/xfr/myfile.zip"
Sending a file with Wget 
wget --post-file="./myfile.zip" --max-redirect=1000000 --server-response --output-document=- "/xfr/myfile.zip"

Keep the command running to host the file. Press CTRL+C to stop.

Receiving files

Receiving a file with cURL 
curl -f -L -J -O -D - "/xfr"
Receiving a file with Wget 
wget --content-disposition --server-response "/xfr"

For folders, encrypted output and other piped input, see the recipes. Prepare the channel before streaming non-rewindable input.
